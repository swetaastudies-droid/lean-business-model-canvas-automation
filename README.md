# 🚀 Lean Business Model Canvas Automation Tool

An AI-assisted entrepreneurship and business-model analysis platform that helps entrepreneurs and students convert a startup idea into a structured Lean Business Model Canvas, identify business-model assumptions, assess confidence and risks, and plan validation activities.

---

## 📌 Project Overview

The **Lean Business Model Canvas Automation Tool** is an entrepreneurship-focused application developed using **Python and Streamlit**.

The tool is designed to support the early-stage startup validation process by converting structured startup information into a nine-block Lean Canvas and providing additional analysis around assumptions, evidence, risks, industry-specific considerations and business-model improvements.

The project follows a structured approach:

**Startup Idea → Problem → Customer → Competitors → Market & Business Model Assumptions → Lean Canvas → Confidence & Risk Analysis → Validation**

The objective is not to treat an AI-generated canvas as a validated business model. Instead, the tool helps entrepreneurs organize hypotheses and identify what still needs to be validated with real-world evidence.

---

# 🎯 Project Objectives

The major objectives of the project are to:

- Automate the initial creation of a Lean Business Model Canvas
- Structure startup information into nine Lean Canvas blocks
- Identify business-model assumptions
- Assess the initial evidence and confidence associated with each canvas block
- Highlight major business-model risks
- Provide industry-specific startup guidance
- Support AI-assisted business-model recommendations
- Provide competitor-analysis functionality using supplied research evidence
- Support collaborative review of canvas assumptions
- Export the Lean Canvas in CSV, Excel and PDF formats
- Provide a deployable Streamlit-based startup analysis application

# 🏢 Startup Case Study: CampusBite

The tool was demonstrated using **CampusBite** as the case startup.

### Industry
FoodTech / Student Services

### Business Model
B2C / Subscription-oriented FoodTech platform

### Target Customer
College students living in:

- Hostels
- Paying Guest accommodation
- Rented accommodation

### Problem

Students living away from home may face difficulty accessing affordable, reliable and convenient everyday meals.

### Proposed Solution

CampusBite is proposed as a platform connecting college students with verified local food providers offering flexible weekly and monthly meal subscriptions.

### Initial Revenue Hypotheses

- Meal subscriptions
- Commission from food providers
- Delivery charges
- Premium meal plans

These revenue streams are treated as **business-model hypotheses requiring validation**, rather than confirmed revenue sources.

# 🧩 Lean Canvas

The application generates the following nine Lean Canvas blocks:

1. Problem
2. Customer Segments
3. Unique Value Proposition
4. Solution
5. Channels
6. Revenue Streams
7. Cost Structure
8. Key Metrics
9. Unfair Advantage

For each area, the project emphasizes the distinction between:

- Current Hypothesis
- Supporting Evidence
- Confidence
- Validation Required

If a defensible competitive advantage has not been established, the tool does not artificially create one.
